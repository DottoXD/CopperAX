# CopperAX

A free & open source anti exploit plugin for your Spigot/Paper-powered Minecraft server.

## Info

CopperAX targets the latest version of Minecraft (1.21.11 at the time of writing this), although older versions have been tested on a production server and showed satisfying results (tested versions include 1.8.8 & 1.12.2).
Hybrid server softwares are not supported. Paper forks such as Pufferfish, Leaf and Purpur are fully supported and have been widely tested.

CopperAX has been running on a few production servers for quite some time and has been closed source since its first release. I felt like open sourcing it due to my loss of interest into managing Minecraft servers and due to Mojang fixing more and more exploits with newer Minecraft versions being released.

## Usage

CopperAX is extremely simple to setup. Just drag the .JAR file from the releases tab to your plugins folder and you're good to go! Please do remember that CopperAX comes with absolutely 0 warranty & responsibility from the author.

## Fixed exploits

Exploits patched by CopperAX include (but are not limited to) trapdoor crashes, lectern crashes, book crashes, spam crashes, sign crashes, end gateway crashes, inventory exploits, location exploits, console exploits, portal exploits, dupe exploits, vehicle exploits, beehive crashes and more.

## Issues and pull requests

Feel free to open an issue for any question, suggestion or any actual issue that you might be facing with CopperAX.
Pull requests are highly appreciated as long as they're widely tested.
